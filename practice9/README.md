# Practice 09 — Python and Pygame

This practice contains three projects created using Python and Pygame.

## 1. Moving Ball
A red ball moves on a white screen using arrow keys.
- Arrow keys move the ball.
- Movement step is 20 pixels.
- The ball cannot move outside the screen.

## 2. Mickey's Clock
An analog clock based on a Mickey Mouse clock image.
- Displays current system time.
- Left hand shows seconds.
- Right hand shows minutes.
- Updates continuously.

## 3. Music Player
A simple music player with two MP3 files.
- P — Play
- S — Stop
- N — Next track
- B — Previous track
- Q — Quit

## Requirements
- Python 3
- Pygame

Install dependencies:

```bash
pip install -r requirements.txt
```

## How to run

### Moving Ball
```bash
python moving_ball/main.py
```

### Mickey's Clock
```bash
python mickeys_clock/main.py
```

### Music Player
```bash
python music_player/main.py
```
