# Music Player

A simple music player created using Python and Pygame.

## Features
- Play music (P)
- Stop music (S)
- Next track (N)
- Previous track (B)
- Quit (Q)
- Display current track and playback status

## Controls

| Key | Action |
|---|---|
| P | Play |
| S | Stop |
| N | Next track |
| B | Previous track |
| Q | Quit |

## Technologies
- Python
- Pygame
- pygame.mixer

## How to run

```bash
python main.py
```
