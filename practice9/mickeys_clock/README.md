# Mickey's Clock

An analog clock created using Python and Pygame with a Mickey-themed clock image.

## Features
- Uses a clock image as the background.
- Displays current system time.
- Left hand shows seconds.
- Right hand shows minutes.
- Clock hands update continuously.

## Technologies
- Python
- Pygame
- Math
- Datetime
- OS

## How to run

```bash
python main.py
```
