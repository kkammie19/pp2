# Moving Ball

A simple Pygame program where a red ball moves on a white screen.

## Features
- Red ball with a radius of 25 pixels.
- White background.
- Arrow keys control the ball.
- Each movement is 20 pixels.
- The ball stays inside the screen boundaries.

## Controls

| Key | Action |
|---|---|
| Up | Move up |
| Down | Move down |
| Left | Move left |
| Right | Move right |

## Technologies
- Python
- Pygame
- pygame.draw

## How to run

```bash
python main.py
```
